## 一、先搞清一件事：你这 40GB 是「免费额度」

官方原文：

> 购买工作站时，**现赠送 100GiB 系统盘及 40GiB 数据盘**，如部署的镜像大小小于赠送值，
> 则无需额外为磁盘付费。

- 你的数据盘 39.9GB ≈ **40GiB，正好就是那块免费盘** → 目前**一分钱没花**
- ★★ **超出赠送值的部分要单独付费，而且是周期性计费 —— 关机也照收。**
  关机只停「算力」，不停「磁盘」。这一点和算力完全不同，必须记牢。

## 二、两条路，先算账再动手

### 路线 A：不扩容（**推荐先试，0 元**）

灵构有一块**平台共享的公共模型盘 `wuying-pub`**，预置了大量热门模型，**已提前挂载到工作站**。
官方原话：「内置公共模型盘解决超大文件下载难题」。

**用软链（symlink）挂过来，不占数据盘一个字节。** 我们本地已有现成脚本：
`D:\xiaobai-claude code\ComfyUI\上云包\scripts\2-灵构-挂模型.sh`

```bash
bash 2-灵构-挂模型.sh              # 看现状
bash 2-灵构-挂模型.sh list flux    # 看模型盘里有没有 flux
bash 2-灵构-挂模型.sh grab flux    # 软链过来（秒完成、0 占盘）
```

⚠️ 默认软链；加 `--copy` 才会真拷贝（那就占盘了，别加）。

**第二条 0 元路：清盘。** 数据盘 40GiB 装不下「Flux 16GB + SDXL 6.5GB + Kontext 12~17GB + 放大模型」
—— 这是**必然爆**的。删掉不再用的对照模型/中间产物即可。

**第三条 0 元路：让 ComfyUI 自己下。** 拖工作流进去点运行，弹窗列缺哪些模型，
点「立即下载」→ 自动落到 `models/` 对应目录，不用手动搬。

### 路线 B：扩容（要花钱，且停机也花）

只有在 A 走完还不够时才做。

## 三、路线 B 官方操作步骤

1. 登录**无影灵构控制台**（`lincore.wuying.aliyun.com`）
2. 左侧导航栏 → **工作站**
3. 找到目标工作站，在卡片**右下角**选 **更多 > 变更数据盘**
4. 在「变更配置」页顶部选择 **变更系统盘** 或 **变更数据盘**
5. 选择扩容后的目标容量，或填**自定义目标容量**
6. 页面底部勾选「已阅读并同意相关协议」→ **立即下单**
7. 在支付页点 **订购**，按提示完成支付

### 硬性限制（官方）

| 项目 | 规则 |
|---|---|
| 扩容粒度 | **必须是 10 的倍数** |
| 单盘上限 | 系统盘、数据盘**各自最大 2000 GiB** |
| 缩容 | ⚠️ **只支持扩容，不支持缩容**。生效后无法变小 → 别一步扩太大 |
| 计费 | 收取**新增容量**的费用；按周期计费，**关机继续收** |
| 前置条件 | 工作站处于「运行中」或「已关机」均可 |

⚠️ **下单页会显示实际金额，务必看清楚「是月费还是总价」再点订购。**
官方未公开单价（随活动浮动），以页面为准。

## 四、扩容完，进系统里容量没变？

需要在操作系统内**手动扩分区**，新增空间才可用。

**Windows 工作站**
1. 右键「开始」→ **磁盘管理**（`diskmgmt.msc`）
2. 右键目标数据盘（通常是「磁盘 1」）→ **扩展卷**
3. 按向导完成 → 新增容量自动并入原分区

**Linux 工作站**（容器镜像）
```bash
sudo su
fdisk -lu            # 看磁盘与分区
df -Th               # 看文件系统类型
growpart /dev/vdb 1  # 扩分区（设备名按 fdisk 结果替换）
resize2fs /dev/vdb1  # ext4；xfs 用 xfs_growfs /挂载点
```

## 五、给你的建议（按顺序做）

1. **先跑 `2-灵构-挂模型.sh list`**，看 Flux / SDXL / Kontext 在不在公共模型盘里
   → 在就软链，**一分钱不花解决**
2. **再清一次数据盘**：40GiB 装全套模型必然不够，这是结构性问题
3. **还是不够 → 扩到 100 GiB**（10 的倍数，够放 Flux + SDXL + Kontext + 放大模型）
   - ⚠️ 不可缩容，**100 是个合适的档，别一步上 200**
   - ⚠️ 记清：这块扩容盘**关机也计费**，是每月固定支出
4. **顺带看一眼系统盘**：C 盘曾只剩 10.74GB，接近满会**导致开机失败**（官方列的三大原因之一）
   → 若系统盘也紧张，可在同一次「变更配置」里一起扩
