# SD 1.5 提示词机制 + 出图参数实测（细节归档）

> `MEMORY.md` 的细节归档。涉及 token 上限、合并机制、防磨皮、闻灯角色出图的实战记录。

## 一、75 token 硬上限（本机 + 远程均适用）

- `comfy/sd1_clip.py` 第 88/487 行 `max_length=77`（含 BOS/EOS）→ **实际可用 75 token**；
  第 638-639 行做**静默截断**，界面不报任何错。
- **ComfyUI 不支持 `BREAK` 长提示词拆分语法**（已遍历源码确认）。
- 精确计数（本机词表 + venv transformers）：
  ```python
  from transformers import CLIPTokenizer
  tk = CLIPTokenizer.from_pretrained(r"D:\xiaobai-claude code\ComfyUI\comfy\sd1_tokenizer")
  n = len(tk.encode("your prompt", add_special_tokens=False))
  ```
  可复用脚本 `_scripts\tok.py`（传 JSON，逐条报告 token 与截断点）。
- 经验值：中文长设定逐字直译 150–200 token，**超一倍以上**，必须分段或精简。
  实例：闻灯设定逐字直译 185 token，截断点恰在「蓝衬衫」之后。
- 出图脚本里**务必内置 token 校验并在超限时拒绝提交**，否则会静默丢词
  （`_scripts\gen_wendeng_v*.py` 就是这个写法）。

## 二、ConditioningCombine 的真实机制（2026-09-16 查源码订正）

- `nodes.py` 的 `ConditioningCombine.combine` = `conditioning_1 + conditioning_2`，
  即把两段 conditioning 作为**两个独立条目**（batch 维度）合并，**不是 token 拼接**。
- `comfy/samplers.py` 的 `_calc_cond_batch`：同一 latent 走
  `out_conds[i] += output[o]*mult[o]` / `out_counts[i] += mult[o]` → 最终是**加权平均**。
- 由此得三条结论：
  1. 每段**各自**受 75 硬上限约束（超了照样静默截断）。
  2. **段数越多，每段话语权被等分稀释**（2 段各 50%，3 段各 33%）。
     → 关键锚点别单独占一段，否则会被摊薄到失效。
  3. 「同一个词分放两段 = 权重接近翻倍」（合并后该词出现两次，均摊后≈2 倍）。
     比写 `(word:2)` 更省 token 也更稳。
- ⚠️ 旧记的「容量扩到约 105 token」**不准确**：容量不是 105，而是「N 段 × 75」个槽位，
  但受平均机制影响，总量越大每段实际影响力越弱。别照旧数字规划。
- **负向同理**：负向也要拆段（每段 ≤75）再用 `ConditioningCombine` 串到 KSampler 的 negative。
  负向段数同样被平均稀释 → 3 段负向时单条词只剩 1/3 权重，压不住就到另一段复述一次。

## 三、出图参数实测

- **磨皮/塑料感的第一主因是分辨率**，不是缺 LoRA。512×640 下脸只占约 110 像素，
  承载不了纹理。修法：512 草稿 → `LatentUpscale`(bislerp) → 第二段 KSampler `denoise 0.45`。
  **denoise 超过 0.7 画面会崩。**
- 摄影原理同样适用：**柔光/浅景深会糊掉皮肤纹理，侧光/硬光才出纹理**。
  正向的 `soft window light` / `shallow depth of field` 是磨皮的帮凶。
- ⚠️ **抑制磨皮要靠正向纹理词，不能靠负向**。正向给足
  `detailed skin texture, skin pores, fine skin details, peach fuzz, film grain, 35mm lens`
  + 侧光/硬光；负向只压**处理痕迹类**（`airbrushed, over-smoothed, beauty filter`）。
  负向**不要**放 `smooth skin / plastic skin / skin` 这类直指皮肤本身的词（会把皮肤推向斑驳）。
- ⚠️ **负向里绝对不要放脸部词**（`bad face / deformed face / asymmetric eyes`）。
  一旦「脸」进了负向，模型发现「画完美脸」难、「干脆不画脸」最容易 → 交白卷，
  得到没有五官的肉色块。想让脸清楚：**正向**写 `detailed face, clear facial features, visible eyes`。
- **排除法判据**：判断是不是「分辨率/硬件不够」，看**更大分辨率那张是不是更好**。
  同样崩 → 排除分辨率与硬件，直接指向提示词。比反复重跑快得多。
- **CFG 别乱降**：为「防脸崩」把 CFG 从 6.5 降到 6.0 是误判，会让模型更不听话、结构更松。
  6.5 是 majicMIX 的稳妥值。
- ⚠️ **种子必须锁 `fixed`**。`KSampler` 的 `control_after_generate` 若为 `randomize`
  则结果完全不可复现。对「女性向底模画男性」这种低概率模式，种子几乎就是开关。
  **20260916 是实测能出男性的种子。**
- ⚠️ **纯白高调布光会把主体一起漂白**（白发、惨白皮肤）。白底需求必须配有方向的光：
  `side lighting, directional light, strong rim light, hard light`，
  不要 `studio lighting + soft even light`（平光），并把发色写实（`black hair`）。
- **纯 CPU 耗时实测（i5-10400F，20 步，dpmpp_2m + karras）**：
  512×640 单段 ≈ 4.2 分钟；512×640→768×960 两段 ≈ 18.3 分钟；512×768 单段 ≈ 6 分钟。
- **远程 RTX 5880 Ada 48G**：512×768 草稿 + 768×1152 高清修复两段，**合计约 8–10 秒**
  （含模型加载）。调参数阶段完全可以在远程跑，不必回本地。

## 四、majicMIX realistic v7 = 女性向底模（画男性的坑）

- 它的「男性」先验天生偏**清秀偶像/韩系美少年**，即用户说的「偏柔弱」。
- 靠提示词能掰到「成年男性」，但**掰不到「有故事感的糙」**。
- **反柔弱词表**：`masculine face, strong jaw, stubble, deep set eyes, thick eyebrows, wiry sinewy build, broad shoulders`
- **推柔弱的词（要避开）**：`slim lean build`、`narrow face`、`pale skin`、`soft features`、`young boy`
- **负向反柔弱**：`delicate, fragile, frail, soft features, pretty boy, boyish face, bishounen, androgynous`
- 用户对闻灯的定调：**「看起来想让人依靠的男人，阳刚但不用太硬」**
  → 保留 `masculine face, strong jaw`，去掉 `gaunt`（憔悴过头）。
- 彻底解决要换**男性向 SD 1.5 写实底模**（Civitai 筛 `Base Model = SD 1.5`）。

## 五、服装词实测对照（白底全身设定图）

| 想要 | 写成 | 写错会变成 |
|---|---|---|
| 洗得发白的蓝色旧衬衫 | `blue button up shirt` | `faded`/`light` → 白 T 恤 |
| 深色旧风衣 | `dark worn trench coat` | `long coat` → 棕色羊毛大衣 |
| 深色长裤 | `dark trousers` | 不写 → 牛仔裤 |
| 全身构图 | `full body shot, head to toe`（**A 段最前**） | 放段末 → 面部特写 |
| 手里拿账簿 | `holding old ledger` + `old ledger`（两段各一次） | 单段末尾 → 完全不出现 |
| 袖口朱砂 | 慎用 `red pigment` | 实测渲染成大衣上的**白漆点** |
| 不露肩 | 负向 `bare chest, shirtless, nude, topless` | 不写 → 直接裸肩 |

## 六、远程 ComfyUI 直连出图（不用浏览器）

`/history` 取到 submit 时的完整 prompt dict → 改词 → `POST /prompt` → 轮询 `/history/<id>` →
`GET /view?filename=..&subfolder=..&type=output` 下载。
- ⚠️ 下载时**必须 `urllib.parse.urlencode` 编码中文文件名**，否则
  `UnicodeEncodeError: 'ascii' codec can't encode`。
- 可复用脚本：`_scripts\gen_wendeng_v8.py`（含内置 token 校验，超限拒绝提交）。
