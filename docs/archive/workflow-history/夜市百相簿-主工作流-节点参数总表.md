### 🔒 身份锁的两把锁（本次调整的核心）

- **结构锚（管身份）**：基图先缩到 512×640、再放回 1024×1280。这一步是低通滤波 ——
  **毛孔 / 发丝 / 皮肤微纹理被彻底抹掉，脸型 / 五官位置 / 比例 / 痣的位置完整保留**；
  再把这张「有骨架没皮肤」的图 `VAEEncode` 成 latent 喂给 KSampler。
- **高 denoise（管表现）**：`d = 0.55`。因为输入本身就模糊，Flux **没有细节可抄 → 必须自己重画**
  毛孔、发丝、光影、景深；而大结构被模糊图锚住 → **人还是那个人**。
- **提示词分层**：`#1301` 身份特征（🔒LOCK）经 `ConditioningConcat` 分别与 `#1310` 正脸表现、
  `#1320` 右脸表现拼接 —— **改身份只改一处，两条支路同时生效**。
- **两个旋钮**：降采样尺寸（`#1303` / `#1307` 的 width/height）= 身份锁强度；
  denoise（`#1313` / `#1323`）= 表现层自由度。

> ★ 要「以 `wendeng_v23_face_base.png` 为基准」，**看身份锁·正脸 / 身份锁·右脸**。
> 支路 A 天生拿不到基图（`EmptySD3LatentImage` 没有图像输入端口），只会按提示词想象一个人。

> ★ Flux 参数红线（与 SDXL 不通用）：`cfg=1.0`、`euler + simple`、`20` 步；
> `cfg=1` 时负向通道 100% 失效（复用 `#1102`）；放大后**不做第二段重绘**。
